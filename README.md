# HexaVault

HexaVault, elektrik-elektronik mühendisleri, hobi elektroniğiyle uğraşanlar (maker'lar) ve laboratuvar yöneticileri için tasarlanmış **sunucusuz, tarayıcı tabanlı bir elektronik malzeme envanter yönetim uygulamasıdır.**

## Kimler Neden Kullanmalı?

- **Mühendisler ve Maker'lar:** Yüzlerce farklı direnç, çip, modül ve sensörün hangi çekmecede olduğunu akılda tutmak zordur. HexaVault, "Bu malzemeden elimde kaldı mı?" veya "Bu kılıftaki entegre hangi kutudaydı?" derdini çözer.
- **Sunucu Kurulumuyla Uğraşmak İstemeyenler:** Uygulama tamamen statiktir. Node.js, SQL veya veritabanı kurmanıza gerek kalmaz. 
- **Hız İsteyenler:** Tüm veriler cihazınızın kendi hafızasında (Local Storage) saklandığı için internet bağlantısına bile ihtiyaç duymaz, ışık hızında arama yapar ve çalışır.
- **Atölye Maliyetini Takip Etmek İsteyenler:** Malzemelerinizi eklerken fiyatlarını da yazıp, atölyenizdeki toplam malzeme değerini tek tıkla görebilirsiniz.
- **Siparişlerini Unutanlar:** "Alınacaklar" sekmesi sayesinde bitecek olan malzemeleri not edebilir, pratik bir alışveriş listesi oluşturabilirsiniz.

## Telefondan Kurulum Nasıl Yapılır?

Uygulamayı telefonunuza tam ekran ve reklamsız bir mobil uygulama gibi kurmak için şu basit adımları izleyin:

1. Bu GitHub sayfasının sağ alt taraflarında bulunan **"Deployments"** bölümünü bulun.
2. Oradaki **"github-pages"** yazısına tıklayın.
3. Sayfanın içinde açılan canlı site linkine tıklayarak uygulamayı telefonunuzun tarayıcısında açın.
4. Tarayıcınızın üst köşesindeki **Üç Nokta (⋮)** veya tarayıcı menüsüne dokunun.
5. Menüden **"Ana Ekrana Ekle"** veya **"Yükle"** seçeneğini seçin.

İşte bu kadar! Artık telefonunuzun ana ekranında uygulamanız belirecek, doğrudan oradan kullanabilirsiniz.

# HexaVault (English)

HexaVault is a **serverless, browser-based electronic component inventory management application** designed for electrical-electronics engineers, hobbyists (makers), and laboratory managers.

## Who Should Use It & Why?

- **Engineers and Makers:** It is hard to remember which drawer holds hundreds of different resistors, chips, modules, and sensors. HexaVault solves the "Do I have this component left?" or "Which box was this IC in?" problem.
- **Those Who Dislike Server Setup:** The application is entirely static. You don't need to install Node.js, SQL, or any database.
- **Speed Seekers:** Since all data is stored locally on your device (Local Storage), it doesn't even need an internet connection. It searches and operates at lightning speed.
- **Cost Trackers:** You can enter the prices while adding components to see the total value of your workshop inventory with a single click.
- **Forgetful Shoppers:** With the "Orders" tab, you can note down the components that are running out and create a practical shopping list with detailed specs.

## How to Install on Mobile?

Follow these simple steps to install the app on your phone to use it full-screen and ad-free like a native app:

1. Look for the **"Deployments"** section on the bottom right of this GitHub page.
2. Click on the **"github-pages"** text.
3. Open the application in your phone's browser by clicking the live site link.
4. Tap the **Three Dots (⋮)** or the browser menu in the top corner.
5. Select **"Add to Home Screen"** or **"Install"** from the menu.

That's it! The application will now appear on your phone's home screen, and you can use it directly from there.
